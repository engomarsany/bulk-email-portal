### 2. Frontend JavaScript Logic Modules
- **[js/state.js](https://github.com/engomarsany/bulk-email-portal/blob/main/js/state.js)** - Central state engine, Mount2ocean default sender credentials, LocalStorage persistence, 20k daily capacity config.
- **[js/ai-optimizer.js](https://github.com/engomarsany/bulk-email-portal/blob/main/js/ai-optimizer.js)** - Gemini AI Email Optimizer Bot knowledge engine (Supports Travels, Medical, B2B, FinTech, Healthcare, SaaS, E-Commerce, Logistics).
- **[js/spam-auditor.js](https://github.com/engomarsany/bulk-email-portal/blob/main/js/spam-auditor.js)** - Spam trigger word scanner, deliverability health meter (0-100%), and opt-out generator.
- **[js/sender.js](https://github.com/engomarsany/bulk-email-portal/blob/main/js/sender.js)** - Sender account & SMTP credentials configuration controller.
- **[js/leads.js](https://github.com/engomarsany/bulk-email-portal/blob/main/js/leads.js)** - CSV target lead importer, company table renderer, and drag-and-drop file attachment uploader.
- **[js/composer-ui.js](https://github.com/engomarsany/bulk-email-portal/blob/main/js/composer-ui.js)** - Email composer controller, dynamic token inserters, and side-by-side AI preview modal controller.
- **[js/spam-auditor-ui.js](https://github.com/engomarsany/bulk-email-portal/blob/main/js/spam-auditor-ui.js)** - Deliverability UI renderer & 1-Click Auto-Fix handler.
- **[js/dispatcher.js](https://github.com/engomarsany/bulk-email-portal/blob/main/js/dispatcher.js)** - Bulk email dispatch engine, staggered delay slider, live terminal console, and real email gateway integration.
- **[js/owner-panel.js](https://github.com/engomarsany/bulk-email-portal/blob/main/js/owner-panel.js)** - Owner oversight dashboard, Chart.js analytics graphs, sent logs table, and raw email inspector modal.
- **[js/app.js](https://github.com/engomarsany/bulk-email-portal/blob/main/js/app.js)** - Main router initialization, tab view switcher, modal backdrop handlers, and toast notification engine.
